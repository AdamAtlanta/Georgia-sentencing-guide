# Website company publication checklist

## Page and search setup

- [ ] The final URL is `/georgia-sentencing-guide/` or another short, permanent Resources URL.
- [ ] The SEO title, meta description, H1, and canonical URL are set.
- [ ] The page is indexable and included in the XML sitemap.
- [ ] The page is linked from the Resources menu and relevant practice-area pages.
- [ ] The page uses the firm's normal header, navigation, footer, contact controls, and analytics.

## Legal notice

- [ ] The complete legal notice appears at the top of the firm-site page before the tool.
- [ ] The same notice appears at the top of the embedded guide.
- [ ] `Adam@SwingleLevin.com` is visible, clickable, and opens a new email.
- [ ] The notice is not hidden inside an accordion, pop-up, or dismissible banner.

## Embedded guide

- [ ] The iframe loads `https://georgia-sentencing-guide.vercel.app/` over HTTPS.
- [ ] The page builder or Content Security Policy permits that URL in an iframe.
- [ ] The guide fills the available width without horizontal scrolling.
- [ ] The `Open the Georgia Sentencing Guide full screen` link is visible so phone users can install the app outside the iframe.
- [ ] The tool remains on the Vercel URL so later guide updates appear automatically.

## Functional test

- [ ] Search for `DUI` and open `DUI - Driving Under the Influence`.
- [ ] Select `First offense`.
- [ ] Confirm the page displays minimum confinement, maximum confinement, minimum fine, maximum fine, and driving/license restrictions.
- [ ] Search for at least one non-driving offense and confirm its sentencing factors and ranges display.
- [ ] Confirm official-source links open in a new tab or window as intended.

## Phone and accessibility test

- [ ] Test the page on an iPhone in Safari.
- [ ] Test the page on a Pixel or other Android phone in Chrome.
- [ ] Confirm the disclaimer is readable without zooming.
- [ ] Confirm the iframe can be scrolled and the search field can be used with the on-screen keyboard.
- [ ] Confirm the page can be navigated with a keyboard and visible focus indicators remain present.
- [ ] Confirm the iframe has the accessible title `Georgia Sentencing Guide by Swingle Levin LLC`.

## Final approval

- [ ] Swingle Levin reviews the final page copy and legal notice.
- [ ] The website company supplies the final firm-site URL to Swingle Levin.
- [ ] The published page is tested once more outside any administrator login session.
- [ ] The vendor supplies every production and staging origin that will frame the tool so framing can later be restricted to approved domains.
